# monalisasroy.github.io

The personal website of Monalisa Singh Roy, served by GitHub Pages at https://monalisasroy.github.io.

A single page of plain HTML with one stylesheet and one script; there is no build step. Images are in `assets/img`: the portrait and the institution logos.

The figure at the top is computed in the page by `assets/site.js`: the probability |J<sub>j</sub>(2Jt)|<sup>2</sup> that a single flipped spin in a chain is found at site j at time t.
